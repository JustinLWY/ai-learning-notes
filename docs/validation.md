# 驗收紀錄

驗收日期：2026-11-10（Asia/Taipei）。環境：Windows、Node.js 24.18.0、已安裝的 Chrome；使用 Playwright Core 進行本機瀏覽器驗收。

## 已通過

- `npm run build`：產生首頁、6 篇文章、關於頁與 404，共 9 頁。
- `npm run check`：6 篇 metadata、3 類分類、9 頁及 199 個站內資源／錨點均通過。所有頁面使用相對連結。
- `npm test`：8 項測試通過，包含程式碼轉義、不安全連結、無效日期、章節格式、來源與路線關聯。
- `node scripts/extension-qa.mjs`：在獨立測試副本先建置五篇，僅新增第六篇 Markdown，再建置成功；書架、workflow 分類數量、全文搜尋資料與新文章頁一起更新。原始內容未刪除。
- `node scripts/browser-qa.mjs`：10 組瀏覽器情境通過，未發現 JavaScript pageerror。

## 瀏覽器情境

1. 首頁完整顯示六篇筆記。
2. 分類、正文搜尋、多條件組合、無結果與重設。
3. 收藏經重新整理仍保留，取消最後一篇後顯示空收藏提示。
4. `/` 聚焦搜尋，Escape 清除搜尋。
5. 文章目錄、已讀保存、路線進度與程式碼複製的成功或失敗回饋。
6. 320、375、768、1440px 的首頁、文章與關於頁皆無整頁橫向溢出。
7. 透過路由模擬 Repository 子路徑，文章與 CSS 正常載入。
8. 損壞的 localStorage 資料不使網站崩潰，後續仍可收藏。
9. localStorage 權限被拒時，保留當次操作並明確提示。
10. 關閉 JavaScript，文章五個章節與程式碼仍可閱讀。

截圖與原始結果儲存在本機 `artifacts/`，不發布瀏覽器測試資料。瀏覽器自動化工具位於 .sites-local，不是網站執行依賴。

## 範圍與限制

外部參考文件曾於製作時開啟查閱；check 不會在每次建置時重抓網際網路。未執行跨瀏覽器矩陣或自動螢幕閱讀器驗收。GitHub Actions／Pages 的實際執行狀態，需待 GitHub 帳號連線後才能確認；本機通過不表示遠端已部署。
